# Preserved ContextCypher reference datasets

These seven files are copied unchanged from the local ContextCypher application's
`server/data/security-knowledge-base/` directory. Their embedded source, version,
last-updated and other metadata are preserved. They are historical reference
snapshots, not a claim that the bundled frameworks are the latest revisions.

Guardian's local GRC workbench derives catalogue counts from the actual records,
retains complete control descriptions, supports family selections, and creates
scoped Statement of Applicability entries. No remote framework download occurs.

The original ContextCypher implementation is Apache-2.0. Third-party framework
content retains its originating ownership; the application license does not
relicense the framework content. Review the source terms before distribution.

CSA Cloud Controls Matrix and IEC 62443 datasets are excluded from the bundled
catalogue and application build. Their supplied JSON files contain source
attribution but no embedded redistribution license. The original local copies
have been retained in the ignored `tmp/restricted-reference-backup/` directory
outside this distributable data directory.

Users can still import their own permitted control sets through CSV/XLSX.
Existing imported workspace records, framework references, and example systems
are preserved; excluding bundled datasets does not remove the user's controls.
