# Contributor instructions

Read and follow [AGENTS.md](AGENTS.md) in full. It is the shared source of truth for current Guardian Agent 2 module ownership, commands, security boundaries, verification, restart handoff and legacy-code restrictions.

Do not create or switch branches without the user's explicit request. Do not fabricate outputs or bypass the shared operation service. Preserve scoped assistant credentials and separate administrator authority. The default application starts from `src/security-main.ts`; the retained assistant runtime is not the default product.
